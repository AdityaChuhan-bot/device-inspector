# Security Policy

## Supported Versions

Device Inspector is actively maintained. Security updates are applied to the latest stable release.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Device Inspector, please do **NOT** open a public issue.

Instead, please report the vulnerability directly to the maintainer via email at:

**`adityachauhan1st@gmail.com`**

Please include:
- A description of the vulnerability.
- Steps to reproduce or proof-of-concept code.
- Potential impact of the issue.

You will receive an acknowledgment within 48 hours, and security patches will be prioritized and released promptly.

Thank you for helping keep Device Inspector secure.

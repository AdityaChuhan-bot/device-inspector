# Changelog

All notable changes to **Device Inspector** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-04

### Added
- 📱 Comprehensive Device Information module (Manufacturer, Model, Brand, Board, Serial, Fingerprint).
- ⚙️ Android OS Details & Build API status.
- 💾 Real-time Memory (RAM) monitoring & breakdown (Total, Available, Threshold, Low RAM warning).
- 📦 Storage Inspector for Internal & External Volumes (Used, Free, Total capacity).
- 🔋 Battery Telemetry (Level, Voltage, Temperature, Health, Technology, Charging Status).
- 🧠 CPU Hardware & Kernel Architecture info (Cores, Architecture, Features, Frequency).
- 📺 Display Metrics (Resolution, Refresh Rate, Density, Screen Size).
- 📷 Camera Specs & Hardware Capability inspection.
- 🌐 Network & Internet Speed Check Module (Ping, Download, Upload, Real-Time Throughput Graph).
- 📡 Sensor Inspector with live sensor list and hardware telemetry.
- 🔍 System Diagnostics & Benchmark Suite.
- 🎨 Cyber-futuristic Material 3 UI theme with Jetpack Compose.
- 🚀 GitHub Actions CI/CD workflow with automatic release APK generation.
